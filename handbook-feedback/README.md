# Handbook Feedback 流程

向 [Handbook](https://aiweb3.school/zh/handbook/) 提交可索引、可开源的反馈，便于团队迭代手册质量。

## 何时写 Feedback？

- 错误（概念、链接、错别字）  
- 讲解不清、与你的背景不匹配  
- 缺例子 / 缺最小实践  
- 正向反馈（哪一节帮你省了时间）  

## 每条建议包含（与启动 Prompt 对齐）

1. **Handbook 页面链接**（完整 URL）  
2. **问题描述**（现象 + 你如何卡住）  
3. **建议改法**（可选但强烈建议）  
4. **来源**：你的学习记录位置（如 `daily/2026-05-18.md` 或本目录下文件名）  

## 操作步骤

1. 复制 [feedback-template.md](feedback-template.md) → `handbook-feedback/feedback-YYYY-MM-DD-简述.md`  
2. 填完后可把摘要发到社区渠道（Discord / GitHub Issues / 营内表单，以当期说明为准）  
3. 在模板末尾填写 **提交链接**；在 [下方索引表](#feedback-记录索引) 增加一行

## Feedback 质量指南

- **具体位置**：章节标题、段落、截图位置  
- **可复现**：他人按你的步骤能否重现困惑  
- **背景**：用 `profile.md` 里一两句话即可，帮助作者判断受众
