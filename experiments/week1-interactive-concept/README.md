# Week 1 · 最小可交互 AI 学习产物

## 运行

- **方式 A**：双击或用浏览器打开 `index.html`（`file://` 即可）。  
- **方式 B**：`npx --yes serve .` 后在本地端口访问（无需构建）。

## 内容说明

- **交互**：选概念 → 读卡片 → 输入自述 → 查看规则化反馈。  
- **无后端 / 无 API Key**：适合公开仓库作业；不涉及任何密钥。  
- **与笔记的关系**：卡片文案与 `submissions/week1-ai-concept-cards.md` 同一学习路线，页面内为精简版。
