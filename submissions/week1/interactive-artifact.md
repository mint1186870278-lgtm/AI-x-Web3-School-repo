# Week 1｜可交互 AI 学习产物 — 提交说明

## 产物位置

- **代码 / 静态页**：[`experiments/week1/interactive-concept/`](../../experiments/week1/interactive-concept/)  
- **打开方式**：克隆仓库后，用浏览器直接打开 `experiments/week1/interactive-concept/index.html`（`file://` 即可），或 `npx serve` 静态托管。

---

## 1. 解决什么学习问题

帮助 **AI / Web3 新手**快速**对照**「一句话解释 + 例子 + 常见误区」，并用**自测输入**强制自己**复述概念**（比只滑动阅读更有效）。

---

## 2. 用户如何与它交互

1. 从下拉框选一个概念（如「LLM」「Prompt」「Agent」）。  
2. 阅读页面展示的**复习卡片**。  
3. 在文本框用**自己的话**写一句理解，点击「生成本页反馈」。  
4. 页面根据**长度与关键词**给出**规则化反馈**（非云端大模型），提示是否覆盖到「概率/幻觉/权限」等要点。

---

## 3. 输入 / 输出示例

**输入示例**（用户自述理解）：

> 「LLM 就是猜下一个词，所以有时会瞎编，我不能全信。」

**输出示例**（页面反馈摘要）：

> 「长度合格。命中要点：概率续写 / 不可靠权威。建议：补一句你如何验证事实（查文档、跑代码、看链上浏览器）。」

另：**输入过短**（如少于 6 个字）会提示写完整一点。

---

## 4. 哪部分 AI 生成，哪部分人工修改 / 验证

| 部分 | 说明 |
|------|--------|
| 卡片正文 | 由学习者整理（与 [`ai-concept-cards.md`](ai-concept-cards.md) 同源思路），**人工重写**后写入 `index.html` 内嵌数据 |
| 交互与反馈规则 | **手写 JS**：字数阈值 + 简单关键词表；**刻意不接 API**，避免在作业仓库存密钥 |
| 验证 | 本地打开页面逐条点选、试短输入/长输入，确认无报错、无外链追踪 |

> **后续改进**：可在 `_可选_` 自配 API Key 的版本中改为调用模型（`.env` **不入库**）。
