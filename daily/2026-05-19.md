**状态**：✅ 已生成草稿，待 push

**核心收获**：
- EOA：单一私钥，最简单，丢了无法找回
- 智能账户（AA）：逻辑在合约里，可设 Session Key、限额、社交恢复，适合 AI Agent 场景
- 多签：需要 M-of-N 联署，适合团队金库或 DAO 治理
- AI Agent 最安全的接入方式：智能账户 + Session Key（可撤销、有限额），而非直接给 EOA 私钥

## 核心 Takeaway（≤ 3 条）

1. AI 钱包（EOA 私钥）不能给 Agent，Session Key 才是安全接入方式
2. Prompt 和 Context Window 决定了 AI 能「看到」和「理解」多少——CLAUDE.md 就是在管理这件事
3. 钱包本质是私钥管理器，助记词泄露等于彻底失控
