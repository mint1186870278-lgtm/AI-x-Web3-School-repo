## 核心 Takeaway（≤ 3 条）

1. Agent 的核心是「循环」，不是单次推理——工具调用、反馈、再推理才构成真正的 Agent
2. Smart Contract 一旦上链不可改，所以审计和权限设计必须在部署前做好
3. Agent Wallet 的安全边界：Agent 拿授权（Session Key），人拿私钥
